Negative values push the video cooler (blue), positive values push it warmer (orange). Needs GPU rendering like Vibrance/Selective color below.
Vibrance boosts dull/muted colors more than already-saturated ones (skin tones move less than a global Saturation boost would).
Softens skin tones for a smoother, beauty-cam look. Eyes, brows, lips and hairline are detected separately and kept sharp so faces don't look blurry overall. Needs GPU rendering like Vibrance/Selective color.
Selective color changes saturation of only the chosen hue (e.g. just reds, or just blues) — other colors stay untouched. Needs GPU rendering, so it only switches on while Vibrance or Selective color saturation are away from 100%.
Settings save automatically and apply to every video you open. Sharpness is simulated edge-enhancement, not true resolution upscaling.
Real-time GPU line-sharpening inspired by the Anime4K algorithm: it detects edges and pushes them crisper, and renders at your screen's resolution instead of the video's, so it also acts as a smart upscale for low-res video. This is a lightweight real-time filter, not a true AI model — genuine AI super-resolution (like ESRGAN/waifu2x) needs a neural network per frame, which is too slow for live video in a browser.
"Noise Reduction" softens grain then re-sharpens edges. "Detail Boost" raises edge contrast. None of these recover detail the source doesn't have — true upscaling needs AI, which a browser filter can't do.
Above 100% uses audio gain amplification — very high boost can distort loud audio.
"My Preset" stores your own saved look. Tap Reset to clear all sliders back to neutral. "Save presets to phone" exports all your saved presets as a file you can keep, share, or move to another device; "Load presets from phone" imports a presets file back in.
